# Atlas Automation

## Purpose

This folder contains automation documentation and guardrails for the Atlas domain.

Atlas automation is guardrail-only because Atlas is the authoritative storage system.

## Initial Classification

`Do not automate storage yet`

## Preferred Automation Tool

- Read-only validation: `pantheonctl`
- Non-destructive checks: `Needs validation`
- Authoritative storage changes: `Do not automate yet`
