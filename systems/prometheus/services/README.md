## Documentation Requirements

Each service folder should include:

- a service document
- `config/README.md`
- `procedures/README.md`

A config folder that says `No Git-backed sanitized config documented yet` is an intentional completeness marker.

A procedure folder that says `No service-specific procedure documented yet` is an intentional completeness marker.
