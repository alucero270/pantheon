# /mnt/local/ssd

## Purpose

This folder mirrors the local SSD mount on Prometheus.

| Field | Value |
|---|---|
| Current live mount | `/mnt/local/ssd` |
| Device | `/dev/mapper/vg_local_ssd-lv_ssd` |
| Filesystem | ext4 |
| Authority | Prometheus-local runtime/service state; not authoritative |
