# /mnt/local/nvme

## Purpose

This folder mirrors the local NVMe mount on Prometheus.

| Field | Value |
|---|---|
| Current live mount | `/mnt/local/nvme` |
| Device | `/dev/nvme0n1p1` |
| Filesystem | ext4 |
| Authority | Prometheus-local runtime/cache; not authoritative |
