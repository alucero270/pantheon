# Network Services

## Folder Purpose

This folder is reserved for network-owned service documentation such as DNS, DHCP, firewall policy services, and VPN/remote-access services after validation.

## Current Service Candidates

- DNS / Unbound - Needs validation
- DHCP - Needs validation
- Firewall rules - Do not automate yet
- Tailscale remote access - Needs validation

## What To Avoid

- Do not hide exposed ports or management surfaces.
- Do not document future remote access as current state.
- Do not automate firewall or switch behavior from this folder.
