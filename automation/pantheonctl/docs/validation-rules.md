# pantheonctl Validation Rules

## Status

status: scaffold

## Initial Rules

- Validate that required root and domain README files exist.
- Validate that wiki links point to existing Markdown files or README indexes.
- Validate that system and service docs include automation classification fields.
- Validate that automation docs do not contain secrets, private keys, or state files.
- Validate that high-risk domains remain guardrail-only until approved.
