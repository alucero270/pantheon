# Shared Ansible Assets

## Purpose

This folder contains reusable Ansible roles and collection declarations for Pantheon.

Prometheus-specific playbooks belong in [[systems/prometheus/automation/ansible/README|Prometheus Ansible Automation]].

## Scope

- reusable roles
- reusable collections
- shared patterns

## Out of Scope

- domain-specific playbooks
- live inventory credentials
- secrets
- firewall or switch automation
- Atlas authoritative storage automation
